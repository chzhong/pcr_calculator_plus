## 合刀计算

指令前缀：`尾刀计算`, `合刀`, `cal`。
<br>
帮助命令（全匹配）：`合刀帮助`, `尾刀计算帮助`, `cal帮助`。
<br>
单独发送「合刀」等常见聊天前缀、或像「合刀了 / 合刀吗」这类不含有效参数的消息时，不会回复，以免干扰正常聊天。

### 说明

**请首先输入boss当前血量B，然后输入每一刀伤害D/T，最后输入期望返还时间E。**

| 参数名 | 参数含义   | 可接受的格式                                                                       |
| ------ | ---------- | -------------------------------------------------------------------------------- |
| B      | boss当前血量 | 1000 1000w 1000W 1000万 10000000 1500-500                                         |
| D      | 对boss造成的伤害 | 1000 1000w 1000W 1000万 1e 1.5e 1.5亿 1k 1m 10000000 1500-500                        |
| T      | 打死boss后剩余时间 | 30 30s 30S 30秒 15+15                                                            |
| E      | 期望返还时间 | 30 30s 30S 30秒 15+15                                                              |

当无量纲时，(90, 100w)被识别为伤害且自动×1w，≤90被识别为秒数。  
参数组合无法识别时会提示常用的 `B D D`（boss 血量、两刀伤害）和 `B D`（boss 血量、单刀伤害）及 `合刀帮助`；数值解析失败时会列出支持的数值写法。
伤害单位新增：`e/亿`（1e=1亿，支持小数，如 1.5e=1.5亿=150000000；换算后须为整数伤害），`k`（1k=1000），`m`（1m=1000000，十进制）。
结果展示规则：伤害值 `<100万` 原样显示；`>=100万` 按“万”向上取整；`>=1亿` 按“亿”向上取整并保留两位小数。
<br>
T相当于B+T的缩写。例如：输入 `cal 700 30s` 相当于 `cal 700 700+30s`。

### 补时计算公式：

其中：\( b \) 为 boss 血量，\( d \) 为造成伤害，\( t \) 为击杀后剩余秒数，\( e \) 为补偿秒数。

$$
e=\min\left(90,\left\lceil 110-\frac{90-t}{d/b}\right\rceil\right)
$$

公式解释：

- 设
  - \( y = 90 - t \)：实际使用时间
  - \( x = d / b \)：伤害相当于 boss 血量的倍数
- 则等效击杀所需时间为 \( y/x \)。
- 对应可返还时间为 \( 90 - y/x = 90 - (90 - t)/(d/b) \)。
- 再额外奖励 20 秒，得到 \( 110 - (90 - t)/(d/b) \)。
- 最后向上取整并封顶 90 秒，即得到上式。


## 时间轴转换

帮助命令：`转秒帮助`、`转补秒帮助`（与 `合刀帮助` 显示同一张完整帮助图）。

按整刀出的长补、近满补：
```
转秒 remain_ts ts1 [ts2 ...]
```
将整刀时间轴上的时间轴换算到剩余 `remain_ts` 秒的时间轴。


转换补偿秒数有差异的补偿刀
```
转补秒 their_remain_ts my_remain_ts ts1 [ts2 ...]
```
将原始补偿秒数（或原轴出售秒数）时间轴换算到自己补偿秒数的时间轴。

> ⚠️ 如果补偿秒数差异太大（15秒以上）建议自行模拟或重新找轴


两个命令均可用空格或换行分隔参数。时间格式支持 `105`、`0105`、`1:05`、`01:05` 等分秒写法。输出采用时间戳列表中最常见的原有样式，补偿秒数无法覆盖的部分会被自动去掉。


### 例子
补偿1:14的刀按原轴打：
```text
转秒 114
105
055
017
016
009
003
```
回复：
```text
049
039
001
TIME UP
```

原26秒的补偿刀作业，自己的刀补偿为31秒：
```
转补秒 26 31
014
011
003
002
```
回复：
```
019
016
008
007
剩余时间请自行模拟
TIME UP
```
